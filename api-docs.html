REST API Documentation

Integrate with NairobiTalks platform using our RESTful API

API Overview

Base URL

http://localhost:3000/api/v1

All API endpoints are prefixed with /api/v1

📊 JSON Responses

All responses are in JSON format with proper HTTP status codes

🔒 Authentication

API uses token-based authentication for protected endpoints

📝 RESTful

Follows REST conventions with proper HTTP methods

Available Endpoints

Community Ideas

GET /api/v1/community_ideas

Retrieve all community ideas with pagination

Parameters:

  • page (integer): Page number (default: 1)
  • per_page (integer): Items per page (default: 20)
  • status (string): Filter by status (approved, pending, rejected)
GET /api/v1/community_ideas/:id

Retrieve a specific community idea by ID

Response includes:

  • Idea details and metadata
  • Author information
  • Vote count and comments
  • Submission status

Response Format

{
  "status": "success",
  "data": [
    {
      "id": 1,
      "title": "Community Garden Initiative",
      "description": "Proposal for urban community gardens...",
      "author": {
        "id": 123,
        "name": "Jane Doe",
        "email": "jane@example.com"
      },
      "votes_count": 45,
      "comments_count": 12,
      "status": "approved",
      "created_at": "2025-01-15T10:30:00Z",
      "updated_at": "2025-01-16T14:20:00Z"
    }
  ],
  "pagination": {
    "current_page": 1,
    "total_pages": 5,
    "total_count": 100,
    "per_page": 20
  }
}

Error Handling

HTTP Status Codes

200 OK Request successful
201 Created Resource created
400 Bad Request Invalid parameters
401 Unauthorized Authentication required
404 Not Found Resource not found
500 Server Error Internal server error

Error Response Format

{
  "status": "error",
  "message": "Resource not found",
  "code": "NOT_FOUND",
  "details": {
    "resource_id": "123"
  }
}

Usage Examples

JavaScript/Fetch

fetch('http://localhost:3000/api/v1/community_ideas')
  .then(response => response.json())
  .then(data => {
    console.log('Community Ideas:', data);
  })
  .catch(error => {
    console.error('Error:', error);
  });

cURL

curl -X GET \
  http://localhost:3000/api/v1/community_ideas \
  -H 'Content-Type: application/json'

Python/Requests

import requests

response = requests.get(
    'http://localhost:3000/api/v1/community_ideas'
)
data = response.json()
print(data)

Ruby

require 'net/http'
require 'json'

uri = URI('http://localhost:3000/api/v1/community_ideas')
response = Net::HTTP.get(uri)
data = JSON.parse(response)
